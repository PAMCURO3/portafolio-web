# Comienzo del Readme

Hemos comenzado con el repositorio, les voy a dejar los comandos utilizados
* Vimos como he creado el repositorio en la nube de Github
* Es importante saber que antes de todo esto se debe tener todos los pasos de ingreso y seguridad
* Cuando hablo de seguridad y conectividad se trata de la ssh, es la clave pública y privada
* Copiamos el enlace ssh
* Abrimos la terminal en Git Bash como administrador
* Ingresamos al área de trabajo donde querremos agregar el repo

```sh
cd documents
mkdir proyectos
cd proyectos
git clone link ssh
cd repo
git pull origin main
git fetch
git branch ahi veran que esta la rama main por defecto
touch Readme.md creamos el readme
git status
git add .
git commit -m "creamos el readme.md"
git status
git push origin main
```
